# Screenshots

Place your dashboard screenshots in this folder:

| Filename                | Contents                              |
|-------------------------|---------------------------------------|
| `dashboard_overview.png`| Full dashboard — all panels visible   |
| `partition_chart.png`   | Bar chart + donut pie chart           |
| `consumer_health.png`   | Health cards with CPU progress bars   |
| `rebalance_log.png`     | Colour-coded rebalance event stream   |

To take screenshots on the running dashboard:
- Open http://localhost:8501 in your browser
- Use your OS screenshot tool, or the browser's built-in screenshot
- Save to this folder with the filenames above
